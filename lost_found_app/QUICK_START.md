# Lost & Found App - Quick Start Guide

## 🚀 Getting Started in 5 Minutes

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Run the Application
```bash
python app.py
```

### Step 3: Open in Browser
```
http://localhost:5000
```

### Step 4: Create Admin Account
- You'll see the setup page on first visit
- Create your admin username and password
- Default item types will be created automatically

## 📋 Navigation

### For Admins
1. **Login** at `/login`
2. **Dashboard** - See statistics and recent activity
3. **Add Found Item** - Register new items with details
4. **Manage Items** - Search, filter, and manage items
5. **Lost Reports** - View student reports and match with found items

### For Users/Students
1. **Search Found Items** - Browse by item type
2. **Report Lost Item** - File a lost item report
3. **View Results** - See found items with shelf locations

## 🔑 Key Features

✅ **Dynamic Item Descriptions** - Different fields based on item type
✅ **Shelf Location Tracking** - Know exactly where items are stored
✅ **Search & Filter** - Find items by type, size, color, location
✅ **Claim Management** - Track who claimed which items
✅ **Report Matching** - Link lost reports to found items
✅ **Professional UI** - Clean, modern, mobile-friendly interface

## 🎯 Common Tasks

### Add a Found Item (Admin)
1. Login → Add Found Item
2. Select item type
3. Fill key details (size, color, etc.)
4. Enter shelf location
5. Click Submit

### Search for Found Item (Student)
1. Go to Search Found Items
2. Select your item type
3. View results with locations
4. Report if it's yours

### Match Lost Report (Admin)
1. Go to Lost Reports
2. Click "Match" on a pending report
3. Select the corresponding found item
4. System matches them automatically
